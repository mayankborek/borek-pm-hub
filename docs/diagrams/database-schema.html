Database schema

Four tables. A task belongs to one project and may be assigned to one user; project_members links users to projects. Version columns provide optimistic locking.

Nothing is deleted

Archive, do not drop

Projects and tasks carry archived_at. No foreign key cascades, so deleting a parent row is blocked while children exist.

The database is the guard

Rules live in constraints

Unique project code, unique TSK key per project, progress 0-100, and a blocked task must have a reason. Python cannot bypass them.
