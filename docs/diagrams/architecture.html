Backend architecture

One API in front of one database. Every request passes middleware, is identified, is checked by can(), and only then reaches the business rules and the data.

Layers

Router, service, database

Routers handle HTTP and permission checks. Services hold the business rules and talk to the database. Nothing else touches the DB.

The one rule

can() decides everything

Every endpoint asks can() before acting. If the UI hides a button, the server still enforces the rule. Non-members get 404, not 403.

Phase 1 shortcut

Dev login, Entra later

Identity comes from the X-Dev-User-Id header. Real sign-in plugs into the Auth provider only; no endpoint changes.
